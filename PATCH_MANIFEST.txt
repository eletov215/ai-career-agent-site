AI Career Agent - AUTH-001 Safari CSRF hotfix manifest

Baseline:
  ai-career-agent-site-main (9).zip from current GitHub main

Problem confirmed in Render logs:
  CSRF validation rejected method=POST path=/auth/register
  reason=The referrer header is missing.

Root cause:
  routes/auth.py forced Referrer-Policy: no-referrer on all /auth responses,
  while production config.py keeps WTF_CSRF_SSL_STRICT=true. Browser POSTs
  therefore omitted Referer and Flask-WTF rejected them before auth/SMTP logic.

Fix:
  Referrer-Policy: strict-origin for /auth responses. This preserves origin-only
  Referer for strict same-origin CSRF checks while stripping path/query token data.

Security invariants:
  WTF_CSRF_ENABLED remains enabled.
  WTF_CSRF_SSL_STRICT remains enabled in production.
  No CSRF exemption added.
  No migration. No environment variable changes. No secrets.

Required gate after GitHub upload:
  full GitHub Actions including Verify AUTH-001 first-party account controls
  then Render redeploy and real Safari registration/verification/reset E2E.
